# Playbook — Promovare plătită

**Regula absolută:** nu pornești, nu oprești, nu modifici nicio campanie, niciun set de
anunțuri, niciun buget, nicio audiență, niciun mijloc de plată. Nici măcar „doar 20 de
lei ca test". Propui, estimezi, analizezi. Atât.

Dacă ai acces tehnic la un cont de reclame, accesul nu e o aprobare.

## Când merită propusă

Reclama amplifică ce funcționează deja. Nu repară ce nu funcționează. Condiții minime
înainte să propui buget:

1. Există cel puțin un articol sau un clip care aduce deja conversații organice.
2. Traseul până la ședința de cunoaștere e clar și testat (pagină → Calendly).
3. Ana are locuri libere în calendar pentru ședințe.
4. Se poate măsura rezultatul (Umami + Calendly), nu doar clicurile.

Dacă una lipsește, recomandă amânarea și spune ce ar trebui făcut întâi. E un răspuns
mai valoros decât o propunere de campanie.

## Structura unei propuneri

```markdown
# Propunere de campanie — [nume], [data]

## Obiectiv
Un singur obiectiv, în cifre: ex. „6 ședințe de cunoaștere programate în 4 săptămâni".

## Ipoteza
„Dacă arătăm [mesajul] către [audiența], atunci [rezultatul], pentru că [motivul]."

## Audiență propusă
- Geografic: …
- Vârstă: …
- Interese / comportamente: …
- Excluderi: …
- **Verificare etică:** nu țintim pe criterii de sănătate, situație psihică sau
  dificultăți financiare, chiar dacă platforma permite.

## Creație
2–3 variante de text + imagine/clip, fiecare cu ce testează.
Toate respectă `../context/voce-si-limbaj.md`: fără promisiuni, fără urgență artificială.

## Destinație
Pagina exactă + eticheta UTM propusă (vezi convenția din
`../context/canale-si-conventii-tehnice.md`; dacă nu există încă una, propune-o aici).

## Buget propus
- Sumă totală: … lei
- Perioadă: … zile
- Buget zilnic: … lei
- **Plafon maxim absolut, dincolo de care campania se oprește: … lei**

## Estimări
Toate marcate ca estimări, cu ipotezele de la care pleacă.
| Indicator | Estimare | Pe ce se bazează |
| afișări | | |
| clicuri | | |
| cost pe clic | | |
| conversații începute | | |
| ședințe programate | | |
| cost estimat pe ședință | | |

Dacă nu ai date istorice, spune-o. „Nu avem încă un punct de referință; prima campanie
e, în principal, o măsurătoare" e un răspuns onest.

## Riscuri
Ce poate merge prost, inclusiv reputațional.

## Criterii de oprire
Ce cifre, la ce moment, înseamnă „oprim".
Ex.: „Dacă după 7 zile și 150 de lei nu există nicio conversație începută, oprim."

## Cine face ce
Ana: pornește, ajustează, oprește. Agentul: pregătește, monitorizează, raportează.

## Ce aprob prin acest document
[ ] bugetul de … lei
[ ] audiențele propuse
[ ] variantele de creație
[ ] pornirea campaniei în perioada …
```

Propunerea se însoțește de o cerere de aprobare (`../sabloane/cerere-aprobare.md`).

## În timpul unei campanii aprobate

- Monitorizezi și raportezi. Nu ajustezi nimic.
- Dacă un criteriu de oprire e atins, îi spui Anei **imediat**, nu la raportul săptămânal,
  și recomanzi oprirea. Oprirea o face ea.
- Dacă apare un comentariu problematic la un anunț, îl semnalezi cu o propunere de
  răspuns. Nu răspunzi tu.

## După campanie

Raport scurt: ce s-a întâmplat, față de ce estimasem, ce am învățat, ce facem altfel.
Include și ce a fost mai prost decât estimarea — mai ales asta.

## Alternative gratuite de recomandat înainte de buget

Recomandă-le explicit când sunt suficiente: legături interne mai bune, teme cu intenție
tranzacțională („coach Iași", „cât costă"), pagina de linkuri, prezența în grupurile
aprobate, refolosirea articolelor bune în clipuri, cerințe simple de SEO local. Costă
timp, nu bani, și cresc un activ care rămâne.
